# Penta Gone off the Wall

![photo of Penta Gone off the wall](./images/photo.png)

## Summary:
Wall decoration. Remix of Non-circular Gear (also in this repo) using the following parameters:

refScale = 11.1  
refEccentricity = 0.6  
numTeethPerLobe = 23  numLobes = 1 and 5  
axleDiameter = 3.5  
thickness = 4  
normalBacklash = 0.4  

Nails are 88 mm from the center.
